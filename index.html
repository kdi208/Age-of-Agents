Claude Code on your computer

  1. Run npx github:kdi208/age-of-agents setup once. It adds hooks to Claude Code. You need Node 18 or newer.
  2. Run npx github:kdi208/age-of-agents. It starts the bridge and opens this HUD, live.

Prefer files? Get them from github.com/kdi208/age-of-agents and run node fleet-bridge.js instead.

Every Claude Code session you start appears as a unit and walks to the folder it is working in. Approve, Deny, Pause, Stop and Redirect act on the real session. Undo the setup with npx github:kdi208/age-of-agents remove.
